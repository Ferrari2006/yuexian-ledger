# 三分钟路演稿

开口不要说「越线」。用报关台的话。

1. **0:00** 打开 `demo/index.html`。这是申报前检查台。单证员要决定：这票现在发不发给海关。
2. **0:20** 点进红色那票。顶栏是「先别申报」。下面并排两张合成样页：装箱单毛重 12480，提单毛重 12000，红底标出这两格。相差 4%。公开清关说明里，毛重偏差超过约 3% 会在自动比对退单。
3. **0:50** 看毛重版本轨迹：装箱是第一次改写，提单和舱单还停在旧值。选择「以装箱单毛重为准」后，系统立即复检；此时仍有第二条阻塞，所以不能放行。
4. **1:20** 第二条：贸易国被写成了原产国。四国口径混成一格，优惠原产地会判错。点「拆分四国字段」，再次复检，页面才变为「可以申报」。
5. **1:50** 依据：这个数是装箱环节改过的，不是模型看漏。抽取误差不计入改写。
6. **2:20** 页脚三个数由规则对全部样例复算：改写落在装箱或舱单、四国混填判错、毛重越过约 3%。
7. **2:40** 边界：只覆盖中国侧、申报前。目的国证书这轮没做。赛题一是另一份运营方案，检查台作为可打开的制品。
