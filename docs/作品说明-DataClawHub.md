# 先别申报 · 赛题二制品说明

上传到 DataClawHub 时，标题用「先别申报」，正文可直接粘贴下面几段。仓库：https://github.com/TinjiYDon/yuexian-ledger

## 一句话

申报发给海关之前，打开一票货，第一眼看到能不能发。现在发，会不会在自动比对被退回。

## 怎么打开

浏览器打开仓库里的 `demo/index.html`。列表里红色的一票是主演示。也可克隆后运行：

```
python -m pip install -e .
python -m unittest discover -s tests -t . -v
python -m yuexian.build_demo
```

## 做什么、不做什么

做：中国侧、申报接受前。比较装箱单与提单的毛重、柜号封条是否第二版、四国口径是否写成一格。抽取看错不算改写。

不做：目的国证书、货运追踪、贸易问答。

## 数据流

单证文本 → 抽取字段 → 按站点对齐 → 规则判定 → 解释。解释不能改判定。页脚三个数由规则复算，不是手填。
