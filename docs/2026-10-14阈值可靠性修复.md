# 毛重阈值可靠性修复

基于主分支 `6cbe25c`，保留队友新加入的调度、批处理与待核验样例。

问题：配置阈值为 NaN 或正无穷时，毛重偏差比较可被跳过；完整数据可能得到 send。原说明中的3%也不能反映自定义阈值。

修改：阈值须为有限数值且 `0 <= threshold < 1`，拒绝布尔、字符串、空值及越界值。无效配置加入 pending，禁止 send；若已有其他冲突仍优先 hold。说明显示实际阈值，并重新生成离线演示。

验证：51项回归测试通过，交稿自检通过。新增覆盖无效阈值、直接规则与输入流水线，以及5%/10%阈值的判定和文案联动。未新增依赖或网络调用。

剩余赛题差距：主分支仍将未接入的PDF/图片等输入回退待核验，尚无完整的HS编码与目的国规则。参考作品已有相关模块，但这次只阅读其架构，没有复制代码或将其能力算成本项目成果。
